# Learning, streaming, and evaluation upgrade

This change strengthens the existing NumPy segmenter without representing its
random transformer features as a pretrained or fully trained language model.

## What changed

- **Learning integrity:** cached examples refresh mutable phase features;
  early stopping restores the head, phase, encoder, and architecture together;
  retraining clears stale best-state/context parameters. Supervision must
  exactly partition the input, including whitespace. CRF transition updates
  now use the same batch averaging as the other learned parameters.
- **Learned lexical features:** optional signed-hashed character unigrams and
  bigrams add seven positional templates to the CRF emission score. The table
  starts at zero, learns through the CRF loss, handles hash collisions, and
  is serialized with a feature-version identifier. The default remains off.
- **Uncertainty in use:** `include_confidence=True` returns CRF marginals,
  mean boundary entropy, and character spans. Streaming can wait for a minimum
  boundary confidence instead of immediately committing an uncertain cut.
- **Streaming correctness:** tiny feeds respect lookahead, unfinished tokens
  remain whole until actual window pressure, model calls and pending buffers
  stay bounded, and malformed outputs cannot silently lose input. Failed
  feeds/flushes restore the wrapper's buffers. Forced cuts at capacity may
  bypass confidence; disabling forced cuts makes overflow an explicit error.
- **AIF computation:** policy candidates and the selected path share one
  feature/encoder pass. Bias-conditioned CRF calculations remain separate.
- **State and delivery:** cached encodings restore matching diagnostics;
  checkpoint saves atomically replace the destination after successful
  serialization; loading clears stale encoding caches. Wheel discovery and
  CI now exercise the actual installed package and the pytest suite.

The PR #84 fresh review added two checkpoint regressions: ambiguous legacy
ownership is rejected before changing student state, and Python checkpoint
loads preserve native availability for subsequent checkpoint swaps. Regression
fixtures were generated by the actual pre-upgrade `8840fee` code with native
test doubles. They establish routing behavior, not native kernel quality.
Encode-cache retention now has LRU entry and array-byte limits (16 entries,
32 MiB by default), including attention matrices; oversized entries are not
copied into the cache. This bounds cache retention, not peak inference memory.

The transformer attention and feed-forward matrices remain fixed random
features. Phase planes and encoder gate scalars use heuristic feedback.
The category NN, context MLP, lexical residual when enabled, and CRF are the
supervised components. Confidence is not externally calibrated. Optional
native models do not implement the lexical residual or the Python confidence
and policy paths; unsupported combinations fail instead of substituting
untrained weights.

## Evaluation protocol

The previous README F1 example used texts that also entered model fitting.
New evaluation groups exact duplicate text, rejects conflicting supervision,
balances sample caps across languages, and creates a seeded held-out test
partition. Internal validation stays entirely inside the remaining training
pool. Partition text hashes and label-manifest hashes are recorded.

The entire bundled corpus contains **33 synthetic examples**. At seed 5042,
the split has 17 optimization examples, 6 internal validation examples, and
10 test examples. Five test examples are English; each of the other five
languages has only one. These are regression experiments, not evidence of
broad multilingual generalization. Exact grouping does not detect near
duplicates, and test folds across seeds overlap.

The independent reference is a whitespace/punctuation rule. Curated teacher
lookup supplies gold labels and is not counted as an independent predictor.
Context/AIF switches on one fitted model are labeled inference ablations.

## Measured results

The [paired lexical ablation](../reports/upgrade-2026-10-05/lexical_ablation.json)
reports mean per-text boundary F1 on each held-out fold:

| Split seed | Lexical off | 4096 buckets | Difference |
| --- | ---: | ---: | ---: |
| 5042 | 0.90390 | 0.91491 | +0.01101 |
| 101 | 0.86789 | 0.87637 | +0.00848 |
| 2026 | 0.86754 | 0.86531 | −0.00222 |
| Mean across seeds | 0.87978 | 0.88553 | +0.00576 |

Two folds improved, one regressed. In seed 2026, both Japanese and Chinese
regressed despite an English improvement. This is why the residual remains
optional. Each non-English language has only one test text per fold; do not
interpret this table as a language-wide ranking or independent repeated trials.

The [AIF timing receipt](../reports/upgrade-2026-10-05/aif_reuse.json) measures
the same outputs with shared versus recomputed features on local arm64 CPU,
Python 3.12.6 / NumPy 2.5.3, nine alternating trials per text:

| Text length | Recomputed median | Shared median | Ratio |
| --- | ---: | ---: | ---: |
| 74 characters | 37.90 ms | 8.70 ms | 4.36× |
| 22 characters | 16.77 ms | 3.78 ms | 4.43× |
| 76 characters | 38.35 ms | 8.42 ms | 4.55× |

All three outputs, policy choices, and scores matched; encoder calls fell from
five to one. This measures this inference optimization on three texts, not
general model speed or quality. The wrapper uses the actual NumPy CPU encoder;
backend telemetry now reports that implementation rather than its C++ wrapper name.

The [full held-out report](../reports/upgrade-2026-10-05/benchmark_report.md)
also includes the independent rule baseline, perturbations, and context/AIF
inference ablations. **291 tests passed** after the PR review fixes, with one optional native-backend test
skipped and nine subtests passing. Native GPU kernels were not validated.

## Reproduce

```bash
pip install -e . pytest build
python -m pytest -q
python -m build
python -c "from spiralreality_AIT_onepass_aifcore_integrated.integrated.benchmark import run_benchmark; run_benchmark(max_samples=None, seed=5042, output_dir='reports/current')"
python scripts/benchmark_lexical.py --output reports/current/lexical_ablation.json
python scripts/benchmark_aif_reuse.py --output reports/current/aif_reuse.json
```

`benchmark_lexical.py` compares 0 versus 4096 buckets with the same split,
initialization, optimizer settings, and internal validation at seeds 5042,
101, and 2026. The seven templates, bucket count, and learning rate were fixed
before evaluating the test data; this is not a search over held-out settings.

`benchmark_aif_reuse.py` compares recomputed and shared features using the
same current trained weights. It checks identical tokens, policy, and policy
scores; counts five versus one encoder passes; warms both paths; alternates
timing order; and records all timing samples. It isolates computation reuse,
not a whole-revision speedup or segmentation-quality gain.

The [initial matched training experiment](../reports/upgrade-2026-10-05/matched_training.json)
is preserved separately. It compares commit `8840fee` (with only three NumPy 2
compatibility casts) against the initial integrity repairs, before the lexical,
CRF batch-scaling, and numerical follow-ups. Uncached macro F1 was unchanged
at 0.906495. Cached macro F1 changed from 0.906996 to 0.906495; micro F1 stayed
0.903509. Those repairs establish consistency, not an observed accuracy gain.

## Remaining work

The main quality constraint is data: add independently sourced, rights-cleared
supervision and a locked external test set before promoting any experimental
feature. Learned lexical capacity can fit distinctions the category-only head
cannot, but small in-repository scores alone do not establish adoption.
AIF observation variances remain configured assumptions and can favor one
policy repeatedly; inspect its histogram and task F1 rather than assuming
policy selection improves the output. Full end-to-end transformer training,
native lexical/confidence kernels, and calibrated confidence are outside this
change.
